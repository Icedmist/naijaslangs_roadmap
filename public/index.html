API Reference Docs

Integrate the API in minutes. Explore simple schemas, parameters, and output layouts.

GET /api/slangs

Fetch and filter the complete dataset of Nigerian street slangs. Perfect for dictionary interfaces and search systems.

Query Parameters

Param Type Description
q string Text search in slang terms, translations, meanings, and tags.
category string Filter by specific categories: finance, lifestyle, personality, expression.
origin string Filter by linguistic origin, e.g. Yoruba, Igbo, Hausa, Pidgin.
page number Pagination page number. Defaults to 1.
limit number Page size limit. Defaults to 10.

cURL Snippet

curl -X GET "https://api.naijaslangs.com/api/slangs?q=sapa&category=finance"
GET /api/slangs/random

Retrieves a randomized slang entry from the database. Extremely useful for "Slang of the Day" features, loading screens, and trivia apps.

cURL Snippet

curl -X GET "https://api.naijaslangs.com/api/slangs/random"
POST /api/slangs

Submit a newly discovered slang directly to the community database. Submissions enter a moderation queue before going live.

JSON Request Body Schema

{
  "slang": "aza",
  "translation": "Account number",
  "meaning": "Street term referencing a bank account number...",
  "examples": ["Send your aza"],
  "category": "finance",
  "origin": "Street Slang",
  "popularity": 5,
  "tags": ["money", "bank"]
}
